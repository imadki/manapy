# Contributing

Contributions of all kinds are welcome — bug reports, documentation, examples,
new solvers, and performance improvements.

The full contribution guide (development setup, running the tests, the pull
request workflow, and how to add a new solver) lives in
[`CONTRIBUTING.md`](https://github.com/imadki/manapy/blob/main/CONTRIBUTING.md) at
the repository root.

- **Report a bug or ask a question:** <https://github.com/imadki/manapy/issues>
- **Run the tests:** `python3 -m pytest tests`
- **Add a solver:** see
  [`manapy/solvers/ADDING_A_SOLVER.md`](https://github.com/imadki/manapy/blob/main/manapy/solvers/ADDING_A_SOLVER.md)
