# Ginkgo Installation Guide

This document provides a complete guide for building Ginkgo from source
with CUDA and OpenMP support on Linux.

------------------------------------------------------------------------

## 1. Install Required Build Tools

Before building Ginkgo, make sure the necessary development tools and
CUDA toolkit are installed:

``` bash
sudo apt update
sudo apt install cmake
sudo apt install nvidia-cuda-toolkit
sudo apt install build-essential
```

------------------------------------------------------------------------

## 2. Prepare the Build Directory

Create a dedicated directory for the build files and navigate into it:

``` bash
mkdir build
cd build
```

------------------------------------------------------------------------

## 3. Configure the Ginkgo Build

Run CMake and specify the desired build parameters:

``` bash
cmake ..     -DCMAKE_BUILD_TYPE=Release     -DGINKGO_BUILD_TESTS=OFF     -DGINKGO_BUILD_BENCHMARKS=OFF     -DGINKGO_BUILD_EXAMPLES=OFF     -DGINKGO_BUILD_REFERENCE=ON     -DGINKGO_BUILD_OMP=ON     -DGINKGO_BUILD_CUDA=ON     -DGINKGO_DOC_GENERATE_EXAMPLES=OFF -DCMAKE_INSTALL_PREFIX=/usr/local
```

### Explanation of Build Options

  --------------------------------------------------------------------------------
Option                               Description
  ------------------------------------ -------------------------------------------
`CMAKE_BUILD_TYPE=Release`           Enables compiler optimizations for
performance.

`GINKGO_BUILD_TESTS=OFF`             Skips building unit tests.

`GINKGO_BUILD_BENCHMARKS=OFF`        Skips benchmark executables.

`GINKGO_BUILD_EXAMPLES=OFF`          Skips example programs.

`GINKGO_BUILD_REFERENCE=ON`          Enables the CPU backend.

`GINKGO_BUILD_OMP=ON`                Enables the OpenMP backend.

`GINKGO_BUILD_CUDA=ON`               Builds the CUDA backend for GPU
acceleration.

`GINKGO_DOC_GENERATE_EXAMPLES=OFF`   Disables documentation example generation.

`CMAKE_INSTALL_PREFIX`               sets the installation path for make install.

--------------------------------------------------------------------------------

This configuration generates a Makefile for a lightweight, optimized
build of Ginkgo with CUDA and OpenMP enabled while excluding optional
components.

------------------------------------------------------------------------

## 4. Build Ginkgo

Compile Ginkgo with:

``` bash
make -j 8
```

You may adjust `-j` based on the number of CPU threads available.

------------------------------------------------------------------------
