# PETSc Linear Solvers and Preconditioners

This document summarizes the **Krylov Subspace Solvers (KSP)** and
**Preconditioners (PC)** available in **PETSc**, with guidance on when to use each.

---

## 1. Krylov Subspace Solvers (KSP)

KSP solvers are iterative methods used to solve linear systems:

Ax = b

They are selected in PETSc with:

```python
ksp.setType("gmres")
```

or at runtime:

```bash
-ksp_type gmres
```

---

### 1.1 Commonly Used KSP Solvers

| KSP type | Description | Typical use |
|--------|------------|-------------|
| cg | Conjugate Gradient | Symmetric Positive Definite (SPD) matrices |
| gmres | Generalized Minimal Residual | General non-symmetric systems |
| fgmres | Flexible GMRES | Variable / nonlinear preconditioners |
| bcgs | BiCGStab | Non-symmetric systems |
| bicg | BiConjugate Gradient | Non-symmetric (less stable) |
| minres | Minimal Residual | Symmetric indefinite systems |
| richardson | Richardson iteration | Smoother / debugging |
| preonly | No Krylov iteration | Direct solvers via PC |

## 2. Preconditioners (PC)

Preconditioners improve convergence and performance and are often
more important than the Krylov solver itself.

Set in PETSc with:

```python
pc.setType("ilu")
```

or at runtime:

```bash
-pc_type ilu
```

---

### 2.1 Commonly Used Preconditioners

| PC type | Description | Typical use |
|-------|------------|-------------|
| none | No preconditioning | Debugging |
| jacobi | Diagonal scaling | Cheap, weak |
| bjacobi | Block Jacobi | MPI-friendly |
| ilu | Incomplete LU | Small / medium problems |
| icc | Incomplete Cholesky | SPD matrices |
| lu | Exact LU | Small direct solves |
| gamg | PETSc AMG | Large PDE systems |
| hypre | HYPRE AMG | Large MPI problems |

## 3. Best-Practice Solver Choices

| Problem type | Recommended KSP | Recommended PC |
|-------------|----------------|----------------|
| SPD | cg | icc / gamg |
| Symmetric indefinite | minres | gamg |
| General sparse | gmres | gamg / hypre |
| Large MPI | fgmres | hypre |
| Direct solve | preonly | lu |

---

## 4. Runtime Configuration

Example:

```bash
mpirun -n 4 python solve.py \
  -ksp_type gmres \
  -pc_type hypre \
  -ksp_rtol 1e-8
```

Make sure your code contains:

```python
ksp.setFromOptions()
```

from petsc4py import PETSc

---

## 6. Key Takeaway

**KSP controls the iteration.  
PC controls performance.**

Choosing a good preconditioner is often more important than choosing the Krylov solver.
